# Sua Empresa Landing

Crie um projeto mínimo chamado "SDR da <sua empresa>". Só uma página inicial em português com o nome da empresa e o texto "Em construção". Ative o Lovable Cloud (banco de dados) e a autenticação por e-mail e senha com uma tela de login simples em /auth, sem confirmação de e-mail. Não crie nenhuma outra tela, tabela ou componente: todo o restante entra pelo GitHub.

This project was built with [Lovable](https://lovable.dev).
